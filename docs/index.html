What the app does

A few useful tools, in one place.

The manager runs outside the game. Its service listens on 127.0.0.1; the browser is its interface. External services are contacted only for features you choose to use.

01 / LOCAL INSPECTION

Know what is installed.

Read addon titles, versions and TOC declarations. Validate the wowf product branch and check for Interface 16001. The manager does not read or modify WTF.

02 / REVIEWED INSTALLATION

Confirm before replacing files.

Inspect a ZIP, its required dependencies and target folders. Installation requires an explicit confirmation with the game stopped. Replaced folders are backed up; a failed installation attempts to restore the previous folders.

03 / AURA TEXT LIBRARY

Keep the string and its source.

Search Wago's public Forever listings or open the website. Save public import text and its source locally. The manager does not decode or execute Lua, import an Aura into the game, or guarantee a work's compatibility.

04 / TRANSLATION JOBS

Make the next instruction readable.

Export a translation job, or explicitly request an AI translation using your own API key. AI API charges are separate. The output is a dictionary: adapting it to an addon's language interface and testing it in game remain separate steps.

CurseForge integration · intended API usage

Official access, with authors' choices respected.

The integration is designed to use the official CurseForge REST API with an approved third-party API key. There is no bundled or shared key. With no configured key, the app provides website search links and local ZIP import.

Planned API use is on demand, in response to a user's action:

  • Search World of Warcraft addons in the Forever category.
  • Read project, version and file metadata to review a selected release.
  • Download a selected file only when the provider supplies a permitted download URL and the author's distribution settings allow it.

If third-party distribution is disabled or a download URL is unavailable, the user is directed to the author's official page. The manager does not guess restricted CDN URLs or bypass paid content, account access or distribution restrictions.

Search responses are not persistently cached. Provider metadata and an Interface declaration do not certify compatibility with a particular client build.

Run it on your computer

Python. A browser.
Your own game directory.

Download and fully extract the source ZIP. Python 3.9 or newer is required; the manager uses the standard library. No pip packages, Node installation or cloud deployment are required.

  1. Run the Windows .cmd or macOS .command launcher in the repository root.
  2. Open the local address printed by the launcher, including its session fragment.
  3. Select the existing _forever_ branch or its Interface/AddOns directory.
  4. Review an installation plan, then close the game before confirming. Restart the game fully after adding a new addon folder.
